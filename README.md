# N-BEATS_data

Датасет для обучения и оценки моделей прогнозирования временных рядов на
архитектуре **N-BEATS**. Используется в методичке по прогнозированию
среднесуточного потребления электроэнергии.

## Файл

`group_b.csv` — один временной ряд, 6059 наблюдений, по одному на сутки.

| Параметр | Значение |
|---|---|
| Колонки | `ds` (дата), `y` (потребление, МВт) |
| Период | 2002-01-01 — 2018-08-03 |
| Записей | 6059 |
| Пропусков в датах | 0 (непрерывный дневной ряд) |
| `y` min / max / mean | 19 769.04 / 52 229.83 / 32 080.03 |

Формат — простой CSV с шапкой, без индекса:

```csv
ds,y
2002-01-01,31080.739130434784
2002-01-02,34261.541666666664
2002-01-03,34511.875
```

### Что такое `y`

Среднесуточное потребление электроэнергии в зоне **PJM East** энергосистемы
**PJM Interconnection** (США). Значения — мегаватты (МВт), усреднённые за сутки.
Дробные значения — результат усреднения часовых замеров, а не ошибка данных.

## Источник

Данные — производные от открытого датасета **PJM Hourly Energy Consumption**
(почасовое потребление электроэнергии, зона PJME).

- **Оригинал:** [PJM Hourly Energy Consumption](https://www.kaggle.com/datasets/robikscube/hourly-energy-consumption)
- **Автор публикации:** [robikscube](https://www.kaggle.com/robikscube) (Kaggle)
- **Исходный файл:** `PJME_hourly.csv`
- **Первоисточник:** [PJM Interconnection](https://www.pjm.com/) — оператор
  энергосистемы, публикует данные в открытом доступе

### Как получен `group_b.csv`

Из почасового ряда `PJME_hourly.csv` (2002–2018 гг.) значения усреднены
по календарным суткам и приведены к виду `ds` / `y`.

## Использование

Скачать напрямую:

```bash
wget https://raw.githubusercontent.com/kenny8/N-BEATS_data/main/group_b.csv
```

Или в Google Colab:

```python
!wget -q -O group_b.csv https://raw.githubusercontent.com/kenny8/N-BEATS_data/main/group_b.csv
```

Загрузка в код:

```python
import pandas as pd

df = pd.read_csv("group_b.csv", parse_dates=["ds"])
```
